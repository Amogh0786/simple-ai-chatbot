# Mercy AI — Next-Gen Intelligent Assistant

A sleek, premium, glassmorphic AI Chatbot web application designed with modern aesthetics, intelligent local conversational synthesis, and seamless multi-provider API integration.

Built with ❤️ by **GANTA BALA AMOGH RAJ (<balaamoghraj@gmail.com>)**  
GitHub: **[@Amogh0786](https://github.com/Amogh0786)**

---

## ✨ Features

- 🌌 **Rich Glassmorphism UI**: High-end dark mode aesthetics with floating animated ambient glow orbs, backdrop blur, and smooth micro-animations.
- 🧠 **Aether Hybrid Neural Engine**: Includes a responsive built-in conversational AI synthesis engine with markdown formatting, syntax highlighting simulation, and preset interactive prompts.
- 🔌 **Multi-Provider API Integration**: Seamlessly switch between **Aether Built-in Hybrid AI**, **Google Gemini API**, **OpenAI (GPT-4o)**, and **Local Ollama**.
- 🔒 **Privacy-First**: API keys and custom system personality instructions are stored locally in your browser's `localStorage`—never transmitted anywhere else.
- ⚡ **Zero Setup**: Runs out-of-the-box as a static web app with vanilla HTML5, CSS3, and modern JavaScript (ES6+).

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Amogh0786/simple-ai-chatbot.git
   cd simple-ai-chatbot
   ```
2. **Open the app**:
   Simply open `index.html` in your favorite modern web browser, or serve it using any HTTP server:
   ```bash
   npx serve .
   ```

## 🛠️ Technology Stack

- **HTML5**: Semantic structure, responsive layouts, inline SVG icons.
- **Vanilla CSS3**: Custom HSL dark-mode palette, CSS variables, glassmorphic filters, keyframe animations.
- **Vanilla JavaScript**: ES6+ modules, local storage persistence, markdown rendering, responsive chat feed.
